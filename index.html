About Library Classification Explorer

What is this?

This tool demonstrates how the same academic subject is classified differently across three major library classification systems: Library of Congress Classification, Dewey Decimal Classification, and Universal Decimal Classification.

Why do classifications differ?

Each system was designed with different philosophical approaches, cultural contexts, and historical periods in mind. They organize knowledge in fundamentally different ways:

  • Library of Congress Classification (1897): Alphabetic system designed for the Library of Congress, extremely detailed
  • Dewey Decimal Classification (1876): Numeric decimal system, designed for general use in libraries worldwide
  • Universal Decimal Classification (1895): Numeric decimal system with extensive auxiliary notation for complex subjects

How to use this tool

  1. Browse subjects using the category buttons or search box
  2. Click any subject to see its classification across all three systems
  3. Compare the call numbers, names, and hierarchy in each system
  4. Read the structural analysis to understand why they differ

Features

  • Search by subject name or classification code
  • Filter by category (Philosophy, Religion, Social Sciences, etc.)
  • Toggle between grouped and flat subject list views
  • View hierarchical relationships within each system
  • See National Library of Medicine classifications for medical subjects

Data Sources

This demo contains over 150 curated subjects with manually verified mappings between the Library of Congress Classification, Dewey Decimal Classification, and Universal Decimal Classification systems. The mappings highlight both direct correspondences and structural divergences that make perfect conversion impossible.

Technical Notes

Pure HTML, CSS, and JavaScript application. No server required. No external dependencies. Works in any modern web browser.
